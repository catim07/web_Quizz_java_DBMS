CÂU 3 (Module 1 - Câu 3): Which files can be multiplexed?
  A. Data Files
  B. Control Files
  C. Parameter Files
  D. Data Buffer Cache

=> ĐÁP ÁN ĐÚNG: B. Control Files
💡 GIẢI THÍCH: Trong kiến trúc hệ quản trị cơ sở dữ liệu Oracle RDBMS, chỉ có **Control Files** và **Online Redo Log Files** là có thể được multiplexed (nhân bản đồng thời ra nhiều ổ đĩa vật lý khác nhau để dự phòng khi một ổ đĩa gặp sự cố). Data files không thể multiplexed bằng cơ chế của Oracle.
🎯 MẸO THI: MẸO PHÒNG THI: Thấy câu hỏi 'Which files can be multiplexed?' trong Oracle -> Chọn ngay 'Control Files' (hoặc 'Redo Log Files')!

  D. Removes all columns from a table

=> ĐÁP ÁN ĐÚNG: B. Removes all rows from a table
💡 GIẢI THÍCH: Lệnh `TRUNCATE TABLE` là một câu lệnh DDL dùng để xóa toàn bộ các dòng dữ liệu (all rows) trong một bảng một cách nhanh chóng và giải phóng dung lượng lưu trữ của bảng. Cấu trúc của bảng (schema) vẫn được giữ nguyên vẹn. Lệnh xóa mất luôn cả bảng khỏi cơ sở dữ liệu là `DROP TABLE`.
🎯 MẸO THI: MẸO PHÒNG THI: Phân biệt rõ: TRUNCATE = Xóa hết tất cả các dòng ('Removes all rows from a table'); DROP = Xóa mất luôn cả bảng ('Removes the table')!

CÂU 42 (Module 3 - Câu 2): Which statement about data types is true?
  A. The CHAR datatype should be used for fixed-length character data
  B. The TIMESTAMP data type is an extension of the VARCHAR2 data type
  C. The BLOB data type stores character data up to four gigabytes
  D. The VARCHAR2 data type stores character data up to four gigabytes

=> ĐÁP ÁN ĐÚNG: A. The CHAR datatype should be used for fixed-length character data
💡 GIẢI THÍCH: Trong Oracle/SQL: Kiểu dữ liệu `CHAR` dùng để lưu trữ chuỗi ký tự có độ dài CỐ ĐỊNH (fixed-length), nếu chuỗi ngắn hơn thì Oracle sẽ tự động bù thêm khoảng trắng; còn `VARCHAR2` dùng cho chuỗi có độ dài BIẾN THIÊN (variable-length) giúp tiết kiệm không gian lưu trữ.
